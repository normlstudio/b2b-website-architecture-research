# B2B website handoff record

A website handoff is complete when the next qualified person can understand what the system owns, why its main decisions were made, and how to change it without recreating the architecture.

Norml Studio uses this record to review the operating layer behind a B2B website. It separates visible evidence from details that require repository, CMS, analytics, design-file, or internal-document access.

## The decision layer

- Name the audiences and the decisions the website must help them make.
- Record the company category, offer, proof, objections, and primary actions.
- Map the buyer routes that connect problem, offer, evidence, and action.

## The page and content system

- List the important page types, templates, reusable components, and interaction states.
- Document which information is structured in the CMS and which content genuinely needs free composition.
- Give navigation, internal links, taxonomies, media, preview, and publishing workflows a clear owner.

## The technical layer

- Record canonical URLs, redirects, crawl rules, sitemap coverage, metadata, and structured information.
- Identify ownership for source control, environments, deployment, analytics, consent, accessibility, performance, and QA.
- Keep credentials outside source code and shared documents.

## The operating handoff

- Name the owner for content, design, code, analytics, credentials, backups, security, dependencies, and maintenance.
- Organize documentation by task or module so a teammate has one place to start.
- Record known limits, decisions, evidence, next actions, and the result of each recheck.
