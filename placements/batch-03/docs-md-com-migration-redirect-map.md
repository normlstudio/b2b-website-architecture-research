# A website migration redirect map should preserve page purpose

A redirect can return the correct status code and still send a reader to a page
that answers a different question. Migration planning should compare meaning,
not only keywords or URL similarity.

## Inventory the old promise

For each indexable URL, record the audience, subject, decision, evidence, next
action, important internal links, backlinks when known, canonical state, and
content owner. Then choose a documented outcome: preserve, merge, replace,
archive, or remove.

When several pages become one, the destination must carry the useful
information they owned. When no honest replacement exists, a clear removal may
be better than routing everything to the homepage.

## Update the full reference system

Redirects are only one layer. Navigation, internal links, canonicals, XML
sitemaps, structured data, alternate-language references, campaign links, and
important controlled profiles should use the new destination. Test chains,
loops, query behavior, case, and trailing slashes on production.
