Production website QA · B2B

Approve the public path, not the build log

A successful deployment proves that a process ran. Release evidence proves that a buyer can use the website that the public host is actually serving.

Release
Record the repository revision, environment, public URL, date, and owner. Confirm production and source control describe the same state.
Journey
Test priority paths: understand a service, inspect evidence, find the team, complete an inquiry, and recover from an error.
System
Check status, canonical, metadata, schema, redirects, consent, analytics, form delivery, responsive layout, and accessibility.
Recovery
Document failed expectations, owners, corrections, complete retests, and the exact rollback route before approval.
