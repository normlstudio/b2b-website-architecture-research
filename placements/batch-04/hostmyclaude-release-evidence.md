# A website release needs evidence beyond a successful deployment

A green build proves that files reached an environment. It does not prove that
the page answers the intended question, that structured content resolved
correctly, that forms reached the right owner, or that important URLs retained
their search meaning.

A release record should connect the change request to the exact revision,
environment, affected URLs, content source, automated checks, visual checks,
conversion-path test, redirect verification, and rollback route. Record the
result after the public URL is available, not only before deployment.
